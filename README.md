# pwnana

Pronounceable, keyboard-alternating password generator.

Like pwgen, but generates passwords that stay **easy to type even when long**.

[日本語版 README](README.ja.md)

## Features

- Character placement that alternates left and right hands on QWERTY
- Pronounceable (CV/VC patterns + vowel-centered digraphs such as oo, ee, ou, ai)
- Digit and symbol insertion via leet substitution (i→!, a→@, e→3, o→0, etc.)
- Symbol set friendly to terminal double-click selection (`-+%~&/_`)
- Option to include one uppercase letter for sites that require it
- Uppercase `O` / `I` are never generated by default, for readability
- Length, count, and options set on the command line (count is always rounded up to even)
- When count is omitted, prints enough passwords to fill about half the terminal height
- Japanese goroawase (number wordplay) passwords are used almost only by Japanese speakers, so they should hold up well against password dictionaries (probably)
- Everyone loves dark mode, right? Old-school green-screen display

## Install

```sh
go build -o ~/.local/bin/pwnana .
```

## Quick usage

```sh
pwnana              # 16 chars × about half the terminal height
pwnana 20 5         # 20 chars × 6 (rounded up to even)
pwnana 24 -d -s     # 24 chars, with digit + symbol
pwnana 24 -d -s -u  # 24 chars, with digit + symbol + uppercase
pwnana --word-symbols  # limit symbols to -+%~&/_
```

## Customization

Just edit `layout`, `digraphs`, and `leet` at the top of `main.go`.
See [docs/manual.md](docs/manual.md) for details.

## Security Notice

**Passwords generated by pwnana are designed for ease of typing and memorability, and their cryptographic strength is not guaranteed.**

- Because generated strings follow pronounceable patterns, they have lower entropy than fully random passwords.
- This tool is intended for use alongside a password manager, or in situations where ease of input matters more than strength.
- Use for financial services, medical information, or other security-critical accounts is not recommended.
- It's perfect for those mysterious corporate "change your password every three months" rules, but use it at your own risk.
